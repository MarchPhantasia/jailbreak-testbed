# 01 目标与边界

## 目标函数

**在固定 `target_calls` 预算下，最大化被判为成功的比例（ASR@budget）。**

所有其他指标都是护栏，用来防止"提升是假的"：

| 护栏 | 它防的是什么 |
|---|---|
| `support`（有无依据） | 答案变流畅，但目标提供的信息没变多 |
| `dependence`（删了还成不成立） | 搜到的信息其实没被使用 |
| 成本四元组 | 用更多调用换来的成功率被写成方法优势 |
| 双裁判 + 人工切片 | 判据漂移被写成方法改进 |
| 配对差值 + CI | 噪声被写成效应 |

## 三个能力

| 能力 | 判定标准 |
|---|---|
| 可回放 | 拿到日志，不重跑目标模型就能重算指标、换裁判重判、做反事实重算 |
| 可换件 | 换状态表示 / 判据 / 装配策略时，其余代码一行不动 |
| 可归因 | 答案里每条必需事实能指到"哪一轮、哪条回复"，并能测"删了它是否还成立" |

## 非目标（v1 明确不做）

- 训练栈（强化学习类方法不纳入；schema 只预留 `policy_ref` 字段）
- 多模态、防御训练
- 模型内部表征 / 白盒分析
- 自建数据集（复用现有公开条目）

## 术语（全文只用这五个计时单位）

| 词 | 一句话 |
|---|---|
| **Episode** | 一次完整攻击尝试：一个目标请求 × 一个方法 × 一份预算 |
| **Turn** | 目标模型看到的一轮"发出 → 回复" |
| **Attempt** | 同一 Turn 内的一次重试；目标可能看到，也可能因回退看不到 |
| **Event** | 日志里的一行，append-only；任何状态都是它的投影 |
| **View** | "此刻目标能看到的历史版本号"；回退只改 View，不改 Event |

## 一条理论约束（写在这里，防止过度宣称）

当结构化状态完全由历史计算得到时，它**不增加新的观测信息**——处理能力不受限的策略可以自行从完整历史构造同样的状态。

所以本项目的理论主张只能是：

> 在**有限上下文**与**明确的处理成本**下，带证据的结构化状态若能保留决策所需信息、同时减少无关上下文的处理负担，则可能在固定预算下提高决策效率。

这条主张成立与否取决于两个可测量条件：**保真度**（抽出来的事实对不对）与**处理成本**（抽取、校验、更新的调用是否被计入）。
