# 27B、外部模型与程序各负责什么

这次选的交付物是一张研究报告卡。读者需要看到正确的分母、可靠的引文，以及一句能解释结论的中文。六张卡取自项目已经公开的汇总，覆盖首次评价、冻结答案重评、历史失败样本、事故未判、人工评审和连接迁移。每张卡的计数来自原记录，两条说明是对公开原文的摘述，待核结论是本次写的评测题。部分记录共享任务或候选，六张卡代表六种报告情境。[样本及原始文档位置](../../data/samples/published-review-cards.json)

## 实际分工

每张卡走三条路径。本地完整组让 27B 计算三个比例、判断待核结论、指出依据并写中文说明。本地分工组和外部分工组把比例交给同一个程序，模型只做其余三项。后一对收到逐字相同的公开计数、短记录和待核句，外部调用独立发生在实验结束后的统计复核阶段。没有把原题、候选正文或历史查询发给外部服务。实验开始前冻结了全部消息的哈希、服务参数、顺序、预期判断和可接受引文，三条路径在每张卡的出场顺序轮换。[实验脚本](../../scripts/calibrate_review_roles.py)

算术检查要求三个比例均正确，语义检查要求在有依据、与记录矛盾和资料不足中选对一项，定位检查直接核对应引的记录编号。中文说明另作逐句阅读，分别检查条件保留、无依据增写、意思改变、转向无关话题和解释缺失。

六张卡三组都通过后，另外冻结了两张真实交叉表的四种可见状态。同样的任务先只给两列各自的计数，再补一项真实的配对信息，检查能否区分“恰好如此”和“只是一种可能”。本地完整组自行求出两边同时命中的可能范围；两种分工组收到从相同计数算出的可行范围，再负责判断和表述。这个追加实验检验给模型提供已验算中间结果的效果。数字参考另用枚举所有可行列联表复核。[交叉表样本及来源](../../data/samples/published-overlap-cards.json)
